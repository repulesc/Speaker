# Speaker list

Facts about stereo speakers, each with a link to where it was read and the day it was read. Facts only: sizes, port, bass limit, driver layout. No copied text, tables or pictures.

- `candidates.json`: the models we mean to cover (names and the expected kind; no specs).
- `entries/`: one JSON file per checked speaker (none yet; the first ones come from the pilot).

How entries are made and checked, and the rules, are in [docs/SPEAKER_DATA.md](../../docs/SPEAKER_DATA.md).
